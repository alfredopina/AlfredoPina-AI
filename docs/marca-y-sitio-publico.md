## Firma de correo (2026-09-26)

**Decisión:** firma HTML con el texto real + UNA imagen (logo principal claro, PNG), no una firma toda en imagen ni en GIF. Por qué: muchos clientes bloquean imágenes por defecto (una firma-imagen queda como cuadro vacío, sin datos copiables); las imágenes se sirven desde `www.alfredopina.ai`, dominio reciente que algunos filtros corporativos aún tratan con desconfianza, así que los datos de contacto también van como texto; y el GIF solo se anima en Gmail/Outlook web (Outlook de escritorio en Windows muestra el primer fotograma — el nuestro empieza sin cursor, degrada bien).

Se instala por copiar/pegar: sirve igual en Gmail y en Outlook, no hay que rehacerla al migrar.
